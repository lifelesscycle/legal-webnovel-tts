About the Project

Webnovel TTS is a personal, self-deployed project created for private use. Its purpose is to provide a convenient way to process web novel text and generate text-to-speech audio.

The application can use Google Drive for storing and retrieving files. Google authentication is handled through Google's OAuth system, using the drive.file permission required by the application.

Webnovel TTS is completely free and is not operated as a commercial service, business, or organization.
